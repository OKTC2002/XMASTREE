# Copilot Chat Quickstart (Print This)

For maintaining the website in VS Code.

## 1) One-Time Setup (5 minutes)

1. Open VS Code.
2. Open Extensions: **Ctrl + Shift + X**.
3. Install:
   - **GitHub Copilot**
   - **GitHub Copilot Chat**
4. Click the **Account** icon in VS Code.
5. Choose **Sign in with GitHub** and approve in browser.
6. Back in VS Code, open Chat:
   - Sidebar Copilot/Chat icon, or
   - **Ctrl + Shift + P** -> type `Chat: Open Chat`

## 2) Daily Workflow (Always This Order)

1. Fetch/Pull latest code in GitHub Desktop
2. Edit with Chat help
3. Test in browser
4. Commit in GitHub Desktop
5. Push in GitHub Desktop

## 3) GitHub Desktop Click Path

1. Open repo in GitHub Desktop
2. Branch: **main**
3. Click **Fetch origin**
4. Click **Pull origin** (if available)
5. Make edits in VS Code
6. Add commit message
7. Click **Commit to main**
8. Click **Push origin**

## 4) If Pull/Push Shows Conflicts

1. Click **Open in Visual Studio Code**
2. Resolve highlighted conflicts
3. Save files
4. Return to GitHub Desktop
5. Click **Mark as resolved**
6. Continue merge and then **Push origin**

## 5) Prompts to Ask Chat

- Explain this file in simple words.
- Improve this section but keep the same meaning.
- Make this page look better on phones.
- Find and fix errors in this file.
- Add a new section for [your text].

## 6) Safety Rules

- Make small changes.
- Test after each change.
- If unsure, ask Chat to explain before accepting.

## 7) One Rule to Remember

**In GitHub Desktop: Fetch/Pull first, then edit, then Commit and Push.**
